# Contenido de docs

Esta carpeta reúne la especificación técnica y funcional del sistema de gestión de inscripciones académicas, organizada por etapas de lectura acumulativa. El recorrido comienza con la problemática institucional, la solución y sus límites, los requerimientos y el análisis funcional; continúa con el modelado, la arquitectura y el diseño de aplicación; y concluye con persistencia, seguridad, operación y verificación.

Cada etapa agrupa un ámbito de decisiones distinto. El orden permite avanzar desde el contexto y las necesidades hacia las responsabilidades técnicas y los criterios de conformidad, sin repetir la misma explicación en varios niveles.
