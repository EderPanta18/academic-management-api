# Contenido de persistencia

Esta carpeta reúne las decisiones de acceso y representación persistente de datos, integridad estructural, transacciones, concurrencia, durabilidad y recuperación. Incluye la preservación de antecedentes y los mecanismos necesarios para conservar efectos confirmados ante fallos o reintentos.

Su alcance son las garantías de almacenamiento y consistencia, sin reiterar el modelo conceptual ni convertir las decisiones de base de datos en reglas de dominio.
