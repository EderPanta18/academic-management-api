# Contenido de aplicación

Esta carpeta agrupa el diseño de coordinación de casos de uso, las convenciones de la API, las operaciones diferidas y las consultas y proyecciones de lectura. Incluye las responsabilidades comunes de aplicación y su concreción en procesos funcionales como las importaciones y los reportes.

Su alcance son los contratos y flujos de aplicación, sin sustituir las reglas del dominio ni repetir los mecanismos de persistencia, mensajería o despliegue.
