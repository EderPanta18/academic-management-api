# Contenido de contexto

Esta carpeta reúne los antecedentes institucionales y la problemática que motiva la gestión de inscripciones académicas. Incluye las dificultades operativas, sus causas, los actores afectados y las consecuencias sobre la consistencia y trazabilidad de la información.

Su alcance es el diagnóstico del problema y las necesidades que lo originan, sin desarrollar todavía la solución ni sus mecanismos técnicos.
