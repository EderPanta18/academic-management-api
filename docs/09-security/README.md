# Contenido de seguridad

Esta carpeta reúne las políticas y mecanismos de autenticación, gestión de sesiones, autorización, protección de solicitudes y auditoría de actuaciones sensibles. Distingue el control de acceso, las defensas de exposición y la conservación de evidencias de seguridad.

Su alcance son las garantías y responsabilidades de protección, sin desarrollar procedimientos operativos ni repetir los casos de uso académicos.
