# Contenido de modelado

Esta carpeta reúne el modelo conceptual del dominio, el modelo lógico de información, las reglas de negocio y los estados y transiciones de las entidades relevantes. Organiza identidades, relaciones e invariantes para precisar el significado y la validez de los datos y operaciones.

Su alcance es la representación estable del dominio y sus restricciones, sin reproducir esquemas físicos, migraciones ni decisiones propias de infraestructura.
