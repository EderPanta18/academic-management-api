# Contenido de análisis funcional

Esta carpeta reúne la identificación de actores, sus objetivos de interacción, los casos de uso, los procesos de negocio y las secuencias funcionales. Expone los recorridos y las colaboraciones necesarias para comprender las operaciones desde la perspectiva de sus participantes.

Su alcance es el comportamiento funcional y sus alternativas, sin detallar componentes de software, estructuras físicas de datos ni mecanismos de ejecución.
