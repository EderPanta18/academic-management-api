# Contenido de arquitectura

Esta carpeta reúne el diseño arquitectónico general, el stack tecnológico, las fronteras y dependencias de módulos, la organización del código fuente y el procesamiento asíncrono. Distingue responsabilidades, contratos y garantías de los mecanismos concretos que las materializan.

Su alcance es la estructura técnica y sus reglas de colaboración, sin detallar contratos HTTP exhaustivos, casos de uso individuales ni procedimientos operativos.
